# Registro dell'esplorazione

Artenaut* Magic Exploration Companion: web app di supporto al gioco da tavolo di esplorazione.

Online su https://artenaut.github.io/esplorazione/

## Principi del progetto

- **Linguaggio inclusivo, sempre.** Nell'app e in tutti i testi pubblici le persone che giocano sono **esplorator\***, oppure si usa una forma neutra («chi gioca», «chi amministra»). Vale per ogni versione in produzione.
